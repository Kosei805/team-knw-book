# ch03 用語点検

章タイトルに含まれる語は点検対象から外し、本文で初めて登場する技術用語を確認するためのメモです。

| 用語 | 初学者に自明か | 本文での初出説明 |
| --- | --- | --- |
| Raspberry Pi Pico H | いいえ | 小型のコンピューター基板として、回路とプログラムを動かす部品だと説明する |
| 回路 | ほぼいいえ | 電気の通り道をつないだものだと説明する |
| 電圧 | ほぼいいえ | 電気を流そうとする力の大きさだと説明する |
| 端子 | いいえ | 基板から出ている金属部分で、ワイヤーをつなぐ場所だと説明する |
| ブレッドボード | いいえ | 部品やワイヤーを穴へ差し込むだけで仮の回路を組める板だと説明する |
| タクトスイッチ | いいえ | 押している間だけ内部の電気の通り道がつながる、押しボタン部品だと説明する |
| ジャンパーワイヤー | いいえ | ブレッドボードの穴同士をつなぐ短い電線だと説明する |
| GP0 | いいえ | Pico Hにある、電圧を読み取るGPIO 0という端子だと説明する |
| GND | いいえ | 回路の電圧を測る基準で、ここでは0V側として使う端子だと説明する |
| GPIO | いいえ | プログラムから電圧を読み書きできる端子だと説明する |
| High / Low | いいえ | 端子の電圧が高い状態・低い状態を表す言葉だと説明する |
| プルアップ | いいえ | スイッチを離したときの入力をHighに保つ設定だと説明する |
| 入力 / 出力 | いいえ | 入力は外部の電圧を読む使い方、出力はプログラムから電圧を決める使い方だと説明する |
| 導通 | いいえ | 2点の間に電気が通る状態だと説明する |
| 状態 | ほぼいいえ | 今その瞬間の「押している・離している」を表す値だと説明する |
| イベント | いいえ | 状態が変わった瞬間に一度だけ起きる出来事だと説明する |
| 接点 | いいえ | スイッチ内部で電気をつないだり切ったりする金属部分だと説明する |
| チャタリング | いいえ | 1回押したのに接点の揺れで複数回の変化に見える現象だと説明する |
| 生値 / 確定値 | いいえ | 生値は読み取った直後の値、確定値は一定時間変わらないことを確認した値だと説明する |
| デバウンス | いいえ | 値が落ち着くまで待ってから1回の押下と判断する処理だと説明する |
| HID | いいえ | キーボードなどの入力機器とOSが通信するための規格だと説明する |
| キーコード | いいえ | Aなどの文字ではなく、どのキーを押したかを表す番号だと説明する |
| レポート | いいえ | HID機器が現在押しているキーの状態をOSへ知らせるデータだと説明する |
| 修飾キー | いいえ | ShiftやControlのように、他のキーと組み合わせて意味を変えるキーだと説明する |
| ビット列 | いいえ | 0と1を並べて、複数のキーの状態をまとめて表すデータだと説明する |
| 予約領域 | いいえ | 今回は使わないため空けておくレポートの欄だと説明する |
| ノイズ | いいえ | 本来の操作ではない短い電気的な変化だと説明する |
| テスター | いいえ | 電圧や電気の通り道を調べる測定器だと説明する |
| シルク印刷 | いいえ | 基板表面に印刷された端子名だと説明する |

コード内だけに現れる変数名やCircuitPythonのAPI名は、登場したコードの直後に役割を説明する。章タイトルに含まれる「キー」「キーボードを作る」は、本文での用語初出点検から除外する。
