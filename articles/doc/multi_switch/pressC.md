# ⚡ マイコン内部で起きていること

**スイッチ3** `(Row 1 × Col 0)` > `Keycode.C`

1. **Picoが GP2（Col 0）を一時的に LOW（0V）に設定する**
   これが「GNDの代わり」になります。専用のGNDピンに繋がなくても、GPIOピン自身が電流の行き先（0V）を作れます。

2. **Picoが GP1（Row 1）の状態を読み取る**
   普段は内部プルアップ抵抗によって 3.3V（High）に保たれています。誰も押していなければ High のままです。

3. **スイッチ3が押され、電気が GP1 → スイッチ → ダイオード → GP2 へ流れる**
   回路がつながったことで GP1 の電圧が 0V（Low）へ引き下げられます。図の光るルートがこの瞬間の電流経路です。

4. **Picoが「GP1 が Low になった」ことを検知する**
   行×列の組み合わせから「スイッチ3」だと特定し、Keycode.C の入力をPCへ送信します。
